# Team 8 Tangible: Games
Github for the group Tangible Games Project: Tic-Tac-Toe

## Instructions For Use:
### Setup:
- Red Player always goes first
- Serial should be set to 9600
- Serial Monitor should be set to 'no line ending'
### Playing:
- Press Green button to change selected LED
- Press Red Button to confirm LED choice
- 3-in-a-row LEDs wins
- Game resets back to red player at the end
